🏎️ Porsche Sales Intelligence

Dashboard interativa desenvolvida para análise e visualização de dados de vendas de veículos Porsche.

O projeto transforma dados comerciais em informações visuais e insights que facilitam a identificação de padrões de vendas, modelos mais procurados, cidades com maior volume e comportamento dos clientes.

🚀 Funcionalidades
🔎 Filtros interativos
Modelo Porsche
Model Year
City
Pay Method
📈 Indicadores (KPIs)
Total de vendas
Ano líder
Modelo líder
Ticket médio
📊 Visualizações
Ranking dos modelos mais vendidos
Vendas por Model Year
Principais cidades
Distribuição por método de pagamento
Insights executivos automáticos
Tabela detalhada das vendas

🛠️ Tecnologias utilizadas
